Are the developer DNS services safe?DNSهای توسعه‌دهنده امن‌اند؟

They are third-party resolvers that see the domains you look up. Use them for package registries and build tooling, not as a privacy tool, and check each provider's site because addresses change.این‌ها ریزالورهای شخص ثالث‌اند و دامنه‌هایی را که جستجو می‌کنید می‌بینند. از آن‌ها برای رجیستری پکیج‌ها و ابزار بیلد استفاده کنید، نه برای حریم خصوصی، و چون آدرس‌ها تغییر می‌کنند سایت هر سرویس را چک کنید.
